## ✨ Features
- **Realistic Interface:** Classic Casio fx-82MS look with tactile button style and dual LCD screen layout.
- **Scientific Operations:** Trigonometry ($\sin, \cos, \tan$), Logarithms ($\log, \ln$), Exponents, Roots, Permutations ($nPr$), Combinations ($nCr$), aur Fractions.
- **Memory & Replay:** Replay navigation keys, memory registers (STO, RCL, M+), aur Answer (Ans) recall.
- **Offline & Lightweight:** Bina internet connection ke fast execution.
